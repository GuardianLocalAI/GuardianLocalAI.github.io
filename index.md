# Guardian — Private AI Assistant

Guardian is an independently developed, privacy-first AI assistant designed to run primarily on local hardware.

## About Guardian

Guardian brings together local AI conversations, personal notes and lists, reminders, alarms, calendar access and optional email integration.

The project prioritises privacy, user control and reliable operation.

## Google Services

Guardian can connect to Google Calendar and Gmail when explicitly authorised by the user.

- **Google Calendar:** Read-only access to calendar events.
- **Gmail:** Read-only access to email messages.

Guardian does not send emails or modify calendar events through these integrations.

Google account access can be revoked by the user at any time.
